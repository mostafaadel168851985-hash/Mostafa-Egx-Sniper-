# تطبيق قناص البورصة المصرية (EGX Sniper) 🇪🇬📈

تطبيق متقدم لمتابعة وتحليل أسهم البورصة المصرية (EGX) باستخدام استراتيجيات التداول الذكية، واكتشاف الاختراقات السعرية، ونماذج الشموع اليابانية، وإشارات الدعم والمقاومة، والتنبيهات اللحظية.

---

## 🚀 كيفية بناء وتحميل ملف الـ APK عبر GitHub Actions

تم تجهيز هذا المستودع بـ **GitHub Actions Workflow** يقوم تلقائياً ببناء ملف الـ APK بمجرد رفع الكود (Push) أو عند الضغط على زر التشغيل اليدوي.

### خطوات تحميل ملف الـ APK:
1. ارفع المشروع إلى مستودعك على **GitHub** (Push).
2. افتح مستودع المشروع على GitHub واضغط على تبويب **Actions** في الشريط العلوي.
3. ستجد سير العمل بعنوان **`Build & Package Android APK`** يعمل تلقائياً (أو يمكنك الضغط على **Run workflow** لتشغيله يدوياً).
4. عند انتهاء البناء ووضع علامة صح خضراء (خلال 3 - 5 دقائق):
   - اضغط على تفاصيل التشغيل (Build Run).
   - انزل لأسفل الصفحة عند قسم **Artifacts**.
   - اضغط على **`EGX-Sniper-App-Debug-APK`** وسيتم تحميل ملف الـ APK مباشرة لجهازك أو هاتفك وتثبيته فوراً!

## ✨ أهم مميزات التطبيق

1. **🔄 تحديث تلقائي كل 15 دقيقة وتحديث يدوي:**
   - أثناء جلسة التداول أو فتح التطبيق، يتم تحديث الأسعار والمؤشرات وحساب الفرص الفنية تلقائياً كل 15 دقيقة.
   - إمكانية التحديث الفوري اليدوي في أي ثانية بضغطة زر.
   - مؤشر يوضح توقيت آخر تحديث تم بنجاح.

2. **📲 مشاركة التحليل الفني لأي سهم على واتساب بنقرة واحدة:**
   - تقرير فني منسق واحترافي يضم: السعر، نسبة التغير، نطاق الدخول، وقف الخسارة، المستهدف الأول والثاني، نسبة العائد للمخاطرة، ونماذج الشموع.
   - يعمل على WhatsApp الرسمي و WhatsApp Business وجميع التطبيقات.

3. **📢 رادار الاكتتابات والإفصاحات والاندماج وزيادة رأس المال:**
   - متابعة طروحات البورصة المصرية الجديدة (IPOs) وبرنامج الطروحات الحكومية والمصرف المتحد.
   - رصد صفقات الاندماج والاستحواذ (M&A) وعروض الشراء الإجبارية.
   - متابعة قرارات زيادة رأس المال والاكتتاب لقدامى المساهمين والأسهم المجانية والتوزيعات النقدية.
   - إمكانية مشاركة أي خبر أو إفصاح مباشرة على واتساب أو الانتقال فوراً لتحليل السهم فنياً.

4. **🎯 محرك الفحص واستراتيجيات قناص الفرص:**
   - **مرشحات الغد:** أفضل الأسهم المرشحة للصعود للجلسة القادمة بناءً على خوارزمية Smart Score (من 100).
   - **قناص الاختراق:** رصد فوري للأسهم التي اخترقت مقاوماتها بسيولة عالية.
   - **صائد التصحيحات & ارتداد الدعم:** التقاط الأسهم القوية عند ملامسة دعومها الرئيسية.
   - **أسهم الشريعة:** تصفية مخصصة للأسهم المتوافقة مع الضوابط الشرعية.

4. **🧮 حاسبة متوسط السعر (DCA Calculator):**
   - حساب تكلفة التبريد وتعديل المتوسط بدقة قبل اتخاذ قرار الشراء.

5. **📖 سجل أداء الصفقات (Journal):**
   - تسجيل الصفقات ومتابعة نسبة الأرباح والخسائر ونسبة نجاح التوصيات (Win Rate).
